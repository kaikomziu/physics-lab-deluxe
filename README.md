# PHYSICS LAB DELUXE - 物理法則プレイグラウンド

表示は2Dだけど中身は本物の3D物理エンジン(Three.js + Cannon.js)。オルソグラフィックカメラで正面から固定して見ているので絵は完全に平面的だが、位置・回転・力の計算はすべて3Dベクトル/クォータニオンで行われている。

公開URL: https://kaikomziu.github.io/physics-lab-deluxe/

## 遊び方
- 上部タブで9つの物理法則モードを切り替え
- 物体をドラッグしてつまみ、離すと実際にその速度で飛んでいく(全モード共通操作)
- 右側(モバイルは☰ボタン)のパネルでモードごとのパラメータ(重力・バネ定数・摩擦係数など)をリアルタイム調整
- 上部の「速さ」スライダーでシミュレーション全体のスローモーション/早送り、⏸で一時停止

## モード一覧
1. 二重振り子 — カオス(初期値鋭敏性)
2. ニュートンのゆりかご — 運動量保存則
3. バネ(単振動) — フックの法則
4. 放物運動 — 空気抵抗ありの弾道
5. 万有引力・軌道 — 逆二乗則での軌道運動
6. 静電気力 — クーロンの法則(引力・斥力)
7. 摩擦と傾斜 — 動摩擦力
8. 浮力 — アルキメデスの原理
9. 自由サンドボックス — 重力の向き/強さを自由に変更できる砂場

## 構成
- `index.html` — ページ本体・UI
- `js/render.js` — Three.jsのシーン/オルソグラフィックカメラ/座標変換
- `js/physics.js` — Cannon.js世界のラッパー(平面拘束・棒/バネの見た目・トレイル管理)
- `js/modes.js` — 9モードの定義(セットアップ・カスタム力・コントロール)
- `js/main.js` — UI配線・ドラッグ操作・メインループ
- `js/version.js` — バージョン・更新履歴

## 開発
ローカル確認はリポジトリルートの `.claude/launch.json` の `physics-lab-deluxe` 設定を使用。
